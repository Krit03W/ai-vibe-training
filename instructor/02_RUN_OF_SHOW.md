**จุดเสี่ยงและแผนสำรอง:**

| ปัญหา | แผนสำรอง |
|---|---|
| เชื่อม GLM ไม่ได้ (401 / key ผิด) | ให้วางบล็อกตั้งค่าในคู่มือ 03 ขั้นที่ 2.1 ใหม่ทั้งบล็อก / แจก key สำรอง |
| GLM ตอบช้าเมื่อใช้พร้อมกันทั้งห้อง | ให้ครึ่งห้องเริ่มขั้นที่ 3 ก่อน อีกครึ่งรอ 1–2 นาที; ทีม AI เฝ้าดู load ของ GLM |
| AI สร้างช้า / usage limit | ให้คนที่ติดดูจอเพื่อนข้าง ๆ; ช่วงบ่ายใช้ทางสำรองคัดลอกไฟล์ตัวอย่าง (ด้านล่าง) |
| เวลาไม่พอ | ข้าม 3.4 (สั่งแก้เฉพาะจุด) ได้ — ขอแค่มี `index.html` ก่อนพักเที่ยง |

**ทางสำรองถ้าคนใดไม่มี `index.html` เลย** (TA วางให้บน VM ผู้อบรม):

```bash
mkdir -p ~/myapp && cat > ~/myapp/index.html <<'EOF'
<!DOCTYPE html>
<html lang="th"><head><meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1">
<title>เครื่องคำนวณวันลาคงเหลือ</title>
<style>body{font-family:sans-serif;max-width:420px;margin:40px auto;padding:0 16px;color:#123}
h1{color:#0b2e6b;font-size:1.4rem}label{display:block;margin-top:12px}input{width:100%;padding:8px;font-size:1rem}
button{margin-top:16px;width:100%;padding:12px;background:#0b2e6b;color:#fff;border:0;font-size:1rem;border-radius:6px}
#out{font-size:3rem;text-align:center;margin-top:20px;color:#0b2e6b}footer{margin-top:40px;font-size:.8rem;color:#666}</style></head>
<body><h1>เครื่องคำนวณวันลาพักผ่อนคงเหลือ</h1>
<label>วันลาพักผ่อนสะสมทั้งหมด<input id="total" type="number" min="0" value="10"></label>
<label>ใช้ไปแล้ว<input id="used" type="number" min="0" value="0"></label>
<button onclick="document.getElementById('out').textContent=Math.max(0,(+total.value||0)-(+used.value||0))+' วัน'">คำนวณ</button>
<div id="out"></div><footer>เครื่องมือนี้สร้างด้วย AI เพื่อการอบรม — ผลคำนวณใช้ประกอบเท่านั้น</footer></body></html>
EOF
```
