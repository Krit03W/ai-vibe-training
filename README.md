# AI + Vibe Coding + Deploy จริง — คู่มือ Workshop

คู่มือประกอบหลักสูตร **"การประยุกต์ใช้ปัญญาประดิษฐ์เพื่อเพิ่มประสิทธิภาพการปฏิบัติงานด้านเทคโนโลยีสารสนเทศและดิจิทัล (ระดับพื้นฐาน)"** สำหรับบุคลากรกรมการจัดหางาน

ตลอดทั้งวัน ผู้เข้าอบรมจะได้ใช้ AI ช่วยงานเอกสาร สร้างเครื่องมือเล็ก ๆ ด้วยการ "สั่งงานเป็นภาษาพูด" (Vibe Coding) ผลิตสื่อประชาสัมพันธ์ เรียนรู้การใช้ AI อย่างปลอดภัย และปิดท้ายด้วยการ **นำเครื่องมือที่สร้างเองขึ้นเว็บจริงผ่านโดเมนของตัวเอง**

> **ไม่ต้องมีพื้นฐานการเขียนโปรแกรม** — ทุกขั้นตอนในคู่มือนี้ออกแบบให้ **คัดลอก (copy) แล้ววาง (paste)** ทีละบล็อก ส่วนการเขียนโปรแกรมให้ AI เป็นคนทำ

## 📚 สำหรับผู้เข้าอบรม — ลำดับการใช้คู่มือ

ทำตามลำดับตัวเลขหน้าชื่อไฟล์:

0. [**00_BEFORE_YOU_START.md**](manual/00_BEFORE_YOU_START.md) — **ก่อนเริ่ม: อ่านบัตร VM, เปิดโปรแกรม Terminal, วิธี copy-paste**
   - ข้อมูลบนบัตร VM แต่ละช่องคืออะไร
   - เปิด PowerShell (Windows) / Terminal (macOS) และวิธีวางข้อความในแต่ละโปรแกรม
1. [**01_PROMPT_WORKSHOP.md**](manual/01_PROMPT_WORKSHOP.md) — **Workshop 1: เขียนคำสั่ง (Prompt) 5 องค์ประกอบ**
   - Template prompt พร้อมคัดลอก สำหรับสรุปเอกสาร / ร่างหนังสือราชการ / สรุปการประชุม
   - เทคนิคให้ตัวอย่าง (one-shot) และสั่งแก้เฉพาะจุด
2. [**02_SSH_VM.md**](manual/02_SSH_VM.md) — **เข้าเครื่อง VM ของตัวเองด้วย SSH**
   - คำสั่ง `ssh` บน Windows / macOS, การพิมพ์รหัสผ่านที่ "มองไม่เห็น"
   - คำสั่งพื้นฐาน 6 คำสั่งที่ต้องรู้ (`pwd`, `ls`, `cd`, `mkdir`, `cat`, `exit`)
3. [**03_VIBE_CODING_WORKSHOP.md**](manual/03_VIBE_CODING_WORKSHOP.md) — **Workshop 2: ติดตั้ง AI CLI (Claude Code) แล้วสั่งสร้างเครื่องมือ**
   - ติดตั้ง Claude Code บน VM, เชื่อมกับ AI GLM ของเรา และติดตั้ง [Engineer Skills](https://github.com/Krit03W/krit-engineer-skills) (`/grill-with-docs`, `/prototype` ฯลฯ)
   - Prompt สำเร็จรูป 5 โจทย์ (เครื่องคำนวณวันลา, แบบฟอร์ม, หน้าแนะนำหน่วยงาน ฯลฯ)
   - ให้ AI สร้างสูตร Excel จากไฟล์ตัวอย่าง
4. [**04_MEDIA_WORKSHOP.md**](manual/04_MEDIA_WORKSHOP.md) — **Workshop 3: ผลิตสื่อด้วย AI — โปสเตอร์ + ตัดต่อวิดีโอ**
   - โครงสร้าง prompt ภาพ 5 ส่วน + prompt ตัวอย่างพร้อมคัดลอก
   - ขั้นตอนใน Canva AI / Ideogram / ChatGPT และหลัก "แก้ ไม่ใช่สร้างใหม่"
   - ให้ Claude Code + GLM ตัดต่อคลิปประชาสัมพันธ์ด้วย [HyperFrames](https://hyperframes.heygen.com) บน VM แล้วดาวน์โหลดเป็น MP4
5. [**05_AI_SAFETY_WORKSHOP.md**](manual/05_AI_SAFETY_WORKSHOP.md) — **Workshop 4: "ใส่ AI ได้ไหม?" + ฝึกปกปิดข้อมูล**
   - สถานการณ์จำลอง 8 ข้อพร้อมเฉลย
   - แบบฝึกหัด masking ข้อมูลส่วนบุคคลก่อนส่งให้ AI
6. [**06_RAG_CONCEPT.md**](manual/06_RAG_CONCEPT.md) — **Module 5: เข้าใจระบบ RAG (ระดับแนวคิด)**

   - คำถามที่ใช้ในการสาธิต และ checklist ถ้าหน่วยงานจะพัฒนาระบบเอง
7. [**07_DEPLOY_CLOUDFLARE.md**](manual/07_DEPLOY_CLOUDFLARE.md) — **Deploy จริง: ขึ้นเว็บด้วย Nginx + Certbot + Cloudflare DNS**

## 🎯 จุดเด่นของคู่มือชุดนี้

- **ทำตามได้ทีละขั้น**: ทุกขั้นมี "✅ ผลที่ควรเห็น" ให้เช็กว่าทำถูกก่อนไปขั้นถัดไป
- **พร้อมคัดลอกรัน**: บล็อกคำสั่งมี `# คำอธิบาย` ภาษาไทยทุกบรรทัด วางลง Terminal ได้ทันที
- **Prompt สำเร็จรูป**: ทุก Workshop มี prompt ตัวอย่างที่ปรับแก้เฉพาะคำในวงเล็บ `[...]` ก็ใช้ได้
- **มีทางสำรองเสมอ**: ถ้า AI ทำไม่สำเร็จ มีคำสั่งสำรองแบบ copy-paste ให้ในกล่อง "🛟 ทางสำรอง"
- **ใช้ตัวอย่างงานราชการ**: เอกสารตัวอย่าง สถานการณ์จำลอง และโจทย์ อิงบริบทงานจัดหางาน
- **ความปลอดภัยมาก่อน**: ข้อมูลตัวอย่างทั้งหมดเป็นข้อมูลสมมติ ไม่มีข้อมูลส่วนบุคคลจริง
