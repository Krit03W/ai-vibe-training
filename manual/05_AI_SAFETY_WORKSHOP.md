# 05 — Module 4: ใช้ AI อย่างปลอดภัยและถูกระเบียบ (Workshop 4)

**เวลา:** 13.00–13.40 น. (40 นาที) · **Workshop 4:** 10 นาที · **รูปแบบ:** อภิปราย + สถานการณ์จำลอง ไม่ใช้ VM

## สิ่งที่ต้องรู้ก่อน

| เรื่อง | จำสั้น ๆ |
|---|---|
| ห้ามนำเข้า AI | **ข้อมูลส่วนบุคคล (PII)** / **ข้อมูลผู้รับบริการ** / **เอกสารลับราชการ** / **รหัสผ่าน & API Key** |
| บัญชีฟรี vs องค์กร | บัญชีฟรีอาจนำข้อมูลไปฝึกโมเดล — บัญชีองค์กรมีข้อตกลงคุ้มครองข้อมูล |
| ถ้าจำเป็นต้องใช้ | **ปกปิดข้อมูลก่อน (Masking)** เช่น "นาย ก." แทนชื่อจริง |
| กฎหมาย | **พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)** + ระเบียบของหน่วยงาน |
| ภัยใหม่ | อีเมลปลอม / ภาพปลอม (Deepfake) / เสียงปลอม (Voice Cloning) ที่สร้างด้วย AI |

## 1. ข้อมูลประเภทใดห้ามนำเข้าระบบ AI

| ประเภท | ตัวอย่าง | ทำไม |
|---|---|---|
| **ข้อมูลส่วนบุคคล (PII)** | ชื่อ-นามสกุล, เลขบัตรประชาชน, เบอร์โทร, ที่อยู่, อีเมล, รูปถ่ายใบหน้า | ระบุตัวบุคคลได้ — อยู่ภายใต้ PDPA |
| **ข้อมูลอ่อนไหว** | ประวัติสุขภาพ, ศาสนา, ประวัติอาชญากรรม, ความพิการ | PDPA คุ้มครองเข้มกว่าข้อมูลทั่วไป |
| **ข้อมูลผู้รับบริการ** | ข้อมูลผู้สมัครงาน, ผู้ประกันตน, แรงงานต่างด้าว, นายจ้าง | หน่วยงานเป็นผู้ควบคุมข้อมูล มีหน้าที่ดูแล |
| **เอกสารลับราชการ** | เอกสารชั้น ลับ / ลับมาก / ลับที่สุด, ร่างนโยบายที่ยังไม่เผยแพร่ | ตามระเบียบว่าด้วยการรักษาความลับของทางราชการ |
| **รหัสผ่าน / API Key / Token** | รหัส VM, API Key ของ AI CLI ที่ใช้เมื่อเช้า | ใครได้ไปก็ใช้แทนเราได้ ค่าใช้จ่ายเกิดกับหน่วยงาน |

> 🔗 **เชื่อมกับ Module 2:** API Key ที่ใช้กับ Claude Code เมื่อเช้า ห้ามพิมพ์ลงในไฟล์ / README / GitHub ที่เผยแพร่สาธารณะ — หลักการเดียวกับข้อมูลส่วนบุคคล: **ข้อมูลที่หลุดไปแล้ว เรียกคืนไม่ได้**

## 2. บัญชีทั่วไป vs บัญชีของหน่วยงาน (Enterprise)

| ประเด็น | บัญชีฟรี / ส่วนตัว | บัญชีองค์กร (Enterprise / Team) |
|---|---|---|
| นำข้อมูลไปฝึกโมเดล | อาจนำไปใช้ (ขึ้นกับการตั้งค่าและนโยบายผู้ให้บริการ) | โดยทั่วไป **ไม่นำไปใช้** ตามสัญญา |
| ระยะเวลาเก็บข้อมูล | ตามนโยบายผู้ให้บริการ | กำหนดได้ตามข้อตกลง |
| ผู้ดูแล / ควบคุมสิทธิ์ | ผู้ใช้คนเดียว | ผู้ดูแลระบบของหน่วยงาน |
| เหมาะกับ | ข้อมูลสาธารณะ / ฝึกใช้งาน | งานของหน่วยงาน (ยังต้องเป็นไปตามระเบียบ) |

> 💡 ถึงจะเป็นบัญชีฟรี ส่วนใหญ่ **ปิดการนำข้อมูลไปฝึกโมเดลได้** ในเมนูตั้งค่า (Settings → Data controls / Privacy) — ตรวจดูของตัวเองหลังอบรม

## 3. เทคนิคปกปิดข้อมูล (Masking) ก่อนนำเข้า AI

| ข้อมูลจริง | ปกปิดเป็น |
|---|---|
| นายสมชาย ใจดี | นาย ก. |
| บริษัท เอบีซี จำกัด | บริษัท X |
| 1-2345-67890-12-3 | X-XXXX-XXXXX-XX-X |
| 081-234-5678 | 0XX-XXX-XXXX |
| 123/4 ถ.พหลโยธิน แขวงสามเสนใน | [ที่อยู่] |
| อายุ 34 ปี | ช่วงอายุ 30–39 ปี |
| เงินเดือน 18,750 บาท | [เงินเดือน] หรือ ช่วง 15,000–20,000 บาท |

### 🧪 แบบฝึกหัด Masking (ข้อมูลสมมติ)

ข้อความต้นฉบับ (สมมติ — ไม่ใช่บุคคลจริง):

```text
เรื่องร้องเรียน: นายสมมติ ทดสอบดี เลขประจำตัวประชาชน 1-1111-11111-11-1 โทร 099-999-9999
ที่อยู่ 99/9 หมู่ 9 ต.ตัวอย่าง อ.สมมติ จ.ทดสอบ อายุ 42 ปี ร้องเรียนว่าบริษัท สมมติการช่าง จำกัด
ไม่จ่ายค่าจ้างเดือนสิงหาคม 2569 จำนวน 15,500 บาท และให้ทำงานล่วงเวลาโดยไม่จ่ายค่าล่วงเวลา
ต้องการให้เจ้าหน้าที่ช่วยไกล่เกลี่ย
```

**โจทย์:** ปกปิดข้อมูลให้ปลอดภัยพอจะส่งให้ AI ช่วย "ร่างหนังสือเชิญนายจ้างมาชี้แจง" ได้

<details>
<summary>👉 คลิกดูเฉลย</summary>

```text
เรื่องร้องเรียน: นาย ก. อายุช่วง 40–49 ปี ร้องเรียนว่าบริษัท X
ไม่จ่ายค่าจ้างเดือนสิงหาคม 2569 และให้ทำงานล่วงเวลาโดยไม่จ่ายค่าล่วงเวลา
ต้องการให้เจ้าหน้าที่ช่วยไกล่เกลี่ย
```

- ตัดเลขบัตร เบอร์โทร ที่อยู่ออกทั้งหมด (ไม่จำเป็นต่องานร่างหนังสือ)
- ชื่อบุคคลและบริษัทแทนด้วย "นาย ก." / "บริษัท X" — ใส่ชื่อจริงเองในไฟล์ Word หลังได้ร่างแล้ว
- จำนวนเงินจะคงไว้หรือตัดก็ได้ ขึ้นกับว่าจำเป็นต่อเนื้อหาหรือไม่ — **หลัก: ส่งเท่าที่จำเป็น (Data Minimization)**

</details>

### Prompt ให้ AI ช่วยตรวจว่ายังมีข้อมูลส่วนบุคคลหลงเหลือไหม

> ⚠️ ใช้กับข้อความที่ปกปิดแล้วเท่านั้น — อย่าส่งข้อความต้นฉบับไปให้ AI ตรวจ

```text
ตรวจข้อความด้านล่างว่ายังมีข้อมูลที่อาจระบุตัวบุคคลหรือนิติบุคคลได้หลงเหลืออยู่หรือไม่
ถ้ามี ให้ชี้จุดและเสนอวิธีปกปิด ห้ามแก้ไขเนื้อหาส่วนอื่น

--- ข้อความ ---
[วางข้อความที่ปกปิดแล้ว]
```

## 4. พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA) — หน้าที่ของผู้ใช้งาน

| หลัก | ความหมายในการใช้ AI |
|---|---|
| **ใช้ตามวัตถุประสงค์** | ข้อมูลที่เก็บมาเพื่อบริการจัดหางาน ไม่ควรนำไปใช้เรื่องอื่น รวมถึงส่งให้ AI ภายนอก |
| **ใช้เท่าที่จำเป็น** (Data Minimization) | ส่งให้ AI เฉพาะส่วนที่จำเป็นต่องาน ตัดส่วนที่ระบุตัวตนออก |
| **รักษาความปลอดภัย** | ไม่ส่งข้อมูลเข้าระบบที่หน่วยงานไม่อนุมัติ |
| **แจ้งเหตุละเมิด** | ถ้าเผลอส่งข้อมูลส่วนบุคคลเข้า AI แล้ว → **แจ้งหัวหน้า / ผู้ดูแลระบบ / DPO ทันที** อย่าเงียบ |

### แนวทางนโยบายการใช้ AI ของหน่วยงาน (ตัวอย่างหัวข้อ)

1. รายชื่อเครื่องมือ AI ที่อนุญาตให้ใช้ และประเภทบัญชี
2. ประเภทข้อมูลที่ห้ามนำเข้า / ต้องปกปิดก่อน
3. งานที่ต้องมีคนตรวจทานก่อนเผยแพร่เสมอ
4. การระบุว่าเนื้อหาสร้างด้วย AI
5. ช่องทางรายงานเหตุผิดปกติ / ข้อมูลรั่วไหล

## 5. ภัยหลอกลวงที่สร้างด้วย AI และวิธีสังเกต

| ภัย | ลักษณะ | วิธีสังเกต / ป้องกัน |
|---|---|---|
| **อีเมลฟิชชิ่ง** | ภาษาเนียน ไม่มีคำผิดแบบเมื่อก่อน อ้างเป็นผู้บริหาร / กรมบัญชีกลาง / ธนาคาร | ดู **อีเมลผู้ส่งจริง** (ไม่ใช่แค่ชื่อที่แสดง), เอาเมาส์ชี้ลิงก์ดู URL ก่อนคลิก, เร่งรัดผิดปกติ = สงสัยไว้ก่อน |
| **ภาพ / วิดีโอปลอม (Deepfake)** | ภาพผู้บริหารพูดสิ่งที่ไม่เคยพูด | แสงเงาไม่สมจริง ขอบหน้า/ผม/หูเบลอ นิ้วมือผิดรูป ปากขยับไม่ตรงเสียง |
| **เสียงปลอม (Voice Cloning)** | โทรมาเสียงเหมือนหัวหน้า / ญาติ ขอให้โอนเงินด่วน | **วางสาย แล้วโทรกลับเบอร์ที่รู้จัก**, ตั้ง "คำลับ" ในครอบครัว / ทีม |

> 📌 **กฎทอง:** เรื่องเงิน / รหัสผ่าน / ข้อมูลลับ + ความเร่งด่วน = **หยุด → ตรวจสอบผ่านช่องทางอื่น → ค่อยทำ**

## 6. 🛠️ Workshop 4: "ใส่ AI ได้ไหม?" (10 นาที)

**กติกา:** วิทยากรอ่านสถานการณ์ → ทุกคนยกป้าย **"ได้" 🟢** หรือ **"ไม่ได้" 🔴** พร้อมกัน → เฉลยพร้อมเหตุผล

| # | สถานการณ์ |
|---|---|
| 1 | นำรายชื่อผู้สมัครงาน 300 คน พร้อมเลขบัตรประชาชน ไปให้ ChatGPT บัญชีส่วนตัวช่วยจัดกลุ่มตามทักษะ |
| 2 | ให้ AI ช่วยร่างประกาศรับสมัครงานนัดพบแรงงาน ที่จะโพสต์บนเพจหน่วยงานอยู่แล้ว |
| 3 | อัปโหลดร่างนโยบายการจ้างงานที่ยังไม่ประกาศ (ชั้นความลับ "ลับ") ให้ AI สรุป |
| 4 | นำสถิติจำนวนผู้ว่างงานรายจังหวัดที่เผยแพร่บนเว็บไซต์แล้ว ให้ AI ทำกราฟและสรุป |
| 5 | คัดลอกเรื่องร้องเรียนของลูกจ้าง (มีชื่อ เบอร์โทร ชื่อบริษัท) ให้ AI ช่วยร่างหนังสือตอบ |
| 6 | เรื่องเดียวกับข้อ 5 แต่ปกปิดเป็น "นาย ก." / "บริษัท X" ตัดเบอร์โทรและที่อยู่ออกก่อน |
| 7 | วาง API Key ของหน่วยงานลงในแชท AI เพื่อถามว่า "ทำไมเชื่อมต่อไม่ได้" |
| 8 | ให้ AI ช่วยเขียนสูตร Excel โดยแปะเฉพาะหัวตารางและข้อมูลตัวอย่างที่แต่งขึ้น 5 แถว |

| # | คำตอบ | เหตุผล |
