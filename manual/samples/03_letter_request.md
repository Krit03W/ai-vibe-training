# ข้อมูลสำหรับยกร่างหนังสือราชการ (ข้อมูลสมมติ)

> ⚠️ เอกสารนี้เป็น **ข้อมูลสมมติ** เพื่อฝึกเขียน prompt ยกร่างหนังสือราชการเท่านั้น

## โจทย์

สำนักงานจัดหางานจังหวัดทดสอบ ต้องการทำหนังสือถึง **ผู้อำนวยการวิทยาลัยเทคนิคจังหวัดทดสอบ** เพื่อขอความร่วมมือประชาสัมพันธ์งานนัดพบแรงงานให้นักศึกษาชั้นปีสุดท้ายและศิษย์เก่า

## ข้อมูลที่ต้องใส่

| รายการ | รายละเอียด |
|---|---|
| ประเภทหนังสือ | หนังสือภายนอก |
| ผู้ส่ง | สำนักงานจัดหางานจังหวัดทดสอบ |
| ผู้รับ | ผู้อำนวยการวิทยาลัยเทคนิคจังหวัดทดสอบ |
| เรื่อง | ขอความร่วมมือประชาสัมพันธ์งานนัดพบแรงงาน |
| ชื่องาน | งานนัดพบแรงงาน ประจำปี 2569 |
| วันเวลา | วันเสาร์ที่ 17 ตุลาคม 2569 เวลา 09.00–15.00 น. |
| สถานที่ | ห้องประชุมใหญ่ ศาลากลางจังหวัดทดสอบ |
| รายละเอียดงาน | สถานประกอบการประมาณ 50 แห่ง ตำแหน่งงานว่างกว่า 1,000 อัตรา เน้นตำแหน่งช่างเทคนิค ช่างซ่อมบำรุง และพนักงานควบคุมเครื่องจักร |
| สิ่งที่ขอความร่วมมือ | 1) ประชาสัมพันธ์ให้นักศึกษาชั้นปีสุดท้ายและศิษย์เก่า 2) อนุญาตให้ติดโปสเตอร์ในวิทยาลัย 3) หากเป็นไปได้ ขอให้จัดรถรับส่งนักศึกษา |
| สิ่งที่ส่งมาด้วย | โปสเตอร์ประชาสัมพันธ์ จำนวน 10 แผ่น |
| ผู้ประสานงาน | กลุ่มงานส่งเสริมการมีงานทำ โทร 0-0000-0000 |

## Prompt ตัวอย่าง (คัดลอกไปใช้ได้)

```text
คุณคือเจ้าหน้าที่ธุรการที่เชี่ยวชาญงานสารบรรณตามระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ
ช่วยยกร่างหนังสือภายนอกจากข้อมูลในตารางด้านล่าง
รูปแบบ: มีส่วน ที่ / ส่วนราชการ / วันที่ / เรื่อง / เรียน / สิ่งที่ส่งมาด้วย / ย่อหน้าเหตุ / ย่อหน้าความประสงค์ / ย่อหน้าสรุป / คำลงท้าย / ส่วนผู้ลงนาม / ส่วนผู้ประสานงาน
ข้อจำกัด: ภาษาราชการสุภาพ กระชับ ไม่เกิน 1 หน้า A4 ข้อมูลที่ไม่ทราบ (เช่น เลขที่หนังสือ ชื่อผู้ลงนาม) ให้เว้นเป็น "........"

[วางตารางข้อมูลที่ต้องใส่]
```
