## วิธีคัดลอกเนื้อหาไปวางในเว็บ AI

1. คลิกชื่อไฟล์
2. กดปุ่ม **Copy raw file** (ไอคอน 📋 มุมขวาบนของเนื้อหาไฟล์)
3. วางในช่องแชทของ AI ต่อท้าย prompt

## วิธีเปิดไฟล์ CSV ใน Excel

1. คลิก [04_visitors_sep2569.csv](04_visitors_sep2569.csv) → กดปุ่ม **Download raw file** (ไอคอน ⬇️)
2. ดับเบิลคลิกไฟล์ที่ดาวน์โหลด จะเปิดใน Excel (ไฟล์บันทึกแบบ UTF-8 with BOM ภาษาไทยจึงแสดงถูกต้อง)
3. ถ้าใช้ Google Sheets: **File → Import → Upload** แล้วเลือกไฟล์
