# เครื่องคำนวณวันลาพักผ่อนคงเหลือ

เว็บหน้าเดียวให้เจ้าหน้าที่ประมาณการวันลาพักผ่อนคงเหลือของตัวเองในปีงบประมาณนี้ ใช้ประกอบเท่านั้น ข้อมูลที่ใช้เป็นทางการคือข้อมูลของงานบุคคล

## Glossary

- **วันลาพักผ่อนประจำปี** — สิทธิ์ลาพักผ่อนที่ได้ใหม่ทุกปีงบประมาณ = 10 วันทำการ
- **วันลาสะสม** — วันลาพักผ่อนที่ไม่ได้ใช้ในปีก่อน ๆ และยกมาปีนี้
- **เพดานสะสม** — จำนวนวันลาพักผ่อนรวมสูงสุดที่มีได้ในปีหนึ่ง: อายุราชการไม่ถึง 10 ปี = 20 วัน · ตั้งแต่ 10 ปีขึ้นไป = 30 วัน
- **สิทธิ์ปีนี้** — `min(10 + วันลาสะสม, เพดานสะสม)`; ถ้าอายุราชการไม่ถึง 6 เดือน = 0
- **วันคงเหลือ** — สิทธิ์ปีนี้ − วันลาพักผ่อนที่ใช้ไปแล้ว

## Project Rules

- หน้าเว็บคือ `index.html` · ตรรกะการคำนวณอยู่ใน `app.js` (ไม่มี backend ไม่ต้อง build)
- ทดสอบด้วย `node --test` (Node.js ในตัว ไม่ต้องติดตั้ง package เพิ่ม)
- ห้ามเก็บหรือส่งข้อมูลที่ผู้ใช้กรอกออกไปที่ไหน ไม่มีช่องข้อมูลส่วนบุคคล
- ข้อความบนหน้าเว็บและข้อความ commit สรุปเป็นภาษาไทยได้
- เซิร์ฟเวอร์ทดสอบ: `python3 -m http.server 8080` แบบ background
- prototype: ทำเป็นไฟล์ `prototype.html` ลบทิ้งเมื่อเลือกแบบแล้ว ไม่ต้องแตก branch
