# Spec: เครื่องคำนวณวันลาพักผ่อนคงเหลือ

## Goal

เจ้าหน้าที่เปิดเว็บหน้าเดียวบนมือถือหรือคอมพิวเตอร์ กรอกอายุราชการ วันลาสะสม และวันลาพักผ่อนที่ใช้ไปแล้ว แล้วเห็น **วันคงเหลือ** เป็นตัวเลขใหญ่ทันทีที่กด "คำนวณ" พร้อมคำเตือนเมื่อเหลือน้อย ใช้ประกอบการวางแผนลาเท่านั้น

## Scope

**In**
- ช่องกรอก 3 ช่อง: อายุราชการ (ปี), วันลาสะสมยกมา (วัน), วันลาพักผ่อนที่ใช้ไปแล้ว (วัน)
- คำนวณสิทธิ์ปีนี้ตามเพดานสะสม (ดู Glossary ใน `CONTEXT.md`)
- ข้อความเตือนเมื่อคงเหลือน้อยกว่า 3 วัน และข้อความแจ้งเมื่อกรอกค่าไม่ถูกต้อง
- หน้าตาทางการ โทนน้ำเงินเข้ม ใช้บนมือถือได้ ภาษาไทยทั้งหมด

**Out (รอบนี้ไม่ทำ)**
- วันลากิจ วันลาป่วย และการลาประเภทอื่น
- การบันทึกข้อมูล การล็อกอิน หรือการเชื่อมระบบงานบุคคล
- การคำนวณจากวันที่บรรจุ (ให้ผู้ใช้กรอกอายุราชการเอง)

## Approach

- `app.js` มีฟังก์ชัน `calculateLeave({ yearsOfService, carriedOver, used })` คืนค่า `{ ok, entitlement, remaining, lowBalance }` หรือ `{ ok: false, errors }` — ไม่แตะหน้าเว็บ จึงทดสอบด้วย `node --test` ได้
- `index.html` อ่านค่าจากฟอร์ม เรียก `LeaveCalc.calculateLeave` แล้วแสดงผล
- หน้าตาแบบทางการราชการ โทนน้ำเงินเข้ม การ์ดเดียวกลางจอ

## Acceptance criteria

- [ ] อายุราชการ 3 ปี · สะสม 5 · ใช้ไป 4 → สิทธิ์ปีนี้ 15 · คงเหลือ 11
- [ ] อายุราชการ 3 ปี · สะสม 15 · ใช้ไป 0 → สิทธิ์ปีนี้ 20 (ชนเพดาน 20)
- [ ] อายุราชการ 12 ปี · สะสม 25 · ใช้ไป 0 → สิทธิ์ปีนี้ 30 (ชนเพดาน 30)
- [ ] อายุราชการ 0.3 ปี → สิทธิ์ปีนี้ 0 และแสดงข้อความ "ยังไม่มีสิทธิ์ลาพักผ่อน (อายุราชการไม่ถึง 6 เดือน)"
- [ ] คงเหลือ 2 วัน → แสดงคำเตือนสีส้ม · คงเหลือ 3 วัน → ไม่เตือน
- [ ] กรอกค่าติดลบ หรือเว้นว่าง → ไม่คำนวณ และแสดงข้อความภาษาไทยบอกช่องที่ผิด
- [ ] ใช้ไปมากกว่าสิทธิ์ → แสดงข้อความ "ใช้เกินสิทธิ์" แทนตัวเลขติดลบ
- [ ] ส่วนท้ายหน้ามีข้อความ "เครื่องมือนี้สร้างด้วย AI เพื่อการอบรม — ผลคำนวณใช้ประกอบเท่านั้น"
- [ ] `node --test` ผ่านทั้งหมด
