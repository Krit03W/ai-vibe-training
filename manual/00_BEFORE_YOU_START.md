## 1. บัตร VM ของคุณ

ตอนลงทะเบียนคุณจะได้รับบัตร 1 ใบ หน้าตาประมาณนี้:

```
┌────────────────────────────────────────────────────────────┐
│  ชื่อผู้อบรม   : นาย/นาง/นางสาว .............................    │
│  VM Public IP : 203.0.113.10                               │
│  SSH Username : admins                                     │
│  SSH Password : (อยู่ในซองแยก)                               │
│  Subdomain    : trainee01.your-training-domain.com         │
└────────────────────────────────────────────────────────────┘
```

| ช่อง | คืออะไร | ใช้ตอนไหน |
|---|---|---|
| **VM Public IP** | "ที่อยู่" ของเครื่องเซิร์ฟเวอร์คุณบนอินเทอร์เน็ต | ตอน SSH และตอนเพิ่ม DNS |
| **SSH Username** | ชื่อผู้ใช้สำหรับเข้าเครื่อง | ตอน SSH |
| **SSH Password** | รหัสผ่านเข้าเครื่อง | ตอน SSH (พิมพ์แล้วจะ **มองไม่เห็น** — ปกติ) |
| **Subdomain** | ชื่อเว็บของคุณที่จะใช้ตอนท้ายวัน | ช่วง Deploy |

> ⚠️ **ชื่อผู้ใช้ SSH ของทุกเครื่องคือ `admins`** · ในคู่มือใช้ `203.0.113.10` เป็น IP ตัวอย่าง และ `trainee01` เป็นชื่อ subdomain ตัวอย่าง — ทุกครั้งที่เห็น ให้เปลี่ยนเป็นของตัวเองตามบัตร
>
> ⚠️ **อย่าถ่ายรูปบัตรลงโซเชียล / กลุ่มไลน์** — ใครมีข้อมูลนี้ก็เข้าเครื่องคุณได้

## 2. เปิดโปรแกรม Terminal

### Windows 10 / 11

**วิธีที่แนะนำ — Windows Terminal** (มีใน Windows 11 อยู่แล้ว):

1. กดปุ่ม `Windows` บนคีย์บอร์ด
2. พิมพ์คำว่า `terminal`
3. กด `Enter`

**ถ้าไม่มี Windows Terminal — ใช้ PowerShell:**

1. กดปุ่ม `Windows`
2. พิมพ์คำว่า `powershell`
3. กด `Enter`

✅ **ผลที่ควรเห็น:** หน้าต่างพื้นดำ/น้ำเงิน มีข้อความประมาณ `PS C:\Users\ชื่อคุณ>` และเคอร์เซอร์กะพริบ

### macOS

1. กด `Command (⌘) + Space`
2. พิมพ์คำว่า `terminal`
3. กด `Enter`

✅ **ผลที่ควรเห็น:** หน้าต่างมีข้อความลงท้ายด้วย `%` หรือ `$`

### ตรวจว่าเครื่องมีคำสั่ง ssh

คัดลอกคำสั่งนี้ไปวางใน Terminal แล้วกด `Enter`:

```bash
ssh -V
```

✅ **ผลที่ควรเห็น:** ข้อความขึ้นต้นด้วย `OpenSSH_...` เช่น `OpenSSH_for_Windows_9.5p1`

❌ ถ้าขึ้นว่า `'ssh' is not recognized` → แจ้ง TA (Windows บางเครื่องต้องเปิดฟีเจอร์ OpenSSH Client ก่อน ดู [09_TROUBLESHOOTING](09_TROUBLESHOOTING.md#ssh-is-not-recognized))

## 3. วิธี Copy-Paste ในแต่ละโปรแกรม

นี่คือทักษะเดียวที่ต้องใช้ทั้งวัน ฝึกให้คล่องก่อนเริ่ม

| โปรแกรม | คัดลอก (Copy) | วาง (Paste) |
|---|---|---|
| **เว็บเบราว์เซอร์ (อ่านคู่มือนี้)** | ลากคลุมข้อความ แล้ว `Ctrl + C` (Mac: `⌘ + C`) หรือกดปุ่ม 📋 มุมขวาบนของกล่องคำสั่ง | — |
| **Windows Terminal** | ลากคลุม แล้ว `Ctrl + Shift + C` | `Ctrl + V` หรือ **คลิกขวา** |
| **PowerShell (หน้าต่างสีน้ำเงิน)** | ลากคลุม แล้วกด `Enter` | **คลิกขวา 1 ครั้ง** |
| **macOS Terminal** | `⌘ + C` | `⌘ + V` |

> 💡 **เคล็ดลับ:** บน GitHub ทุกกล่องคำสั่งจะมีปุ่ม **📋 (Copy)** ที่มุมขวาบนเมื่อเอาเมาส์ไปชี้ — กดปุ่มนี้ง่ายและแม่นกว่าการลากคลุม

### ฝึกลองวาง

คัดลอกบล็อกนี้ไปวางใน Terminal แล้วกด `Enter`:

```bash
echo "สวัสดีครับ ผมพร้อมอบรมแล้ว"
```

✅ **ผลที่ควรเห็น:** Terminal พิมพ์ข้อความ `สวัสดีครับ ผมพร้อมอบรมแล้ว` กลับมา

> ถ้าภาษาไทยแสดงเป็นเครื่องหมาย `?????` ไม่ต้องกังวล ไม่มีผลต่อการอบรม (เกิดจากฟอนต์ของ PowerShell รุ่นเก่า — ใช้ Windows Terminal จะแสดงถูกต้อง)
