## 2.1 Vibe Coding คืออะไร

```text
  👤 เรา                     🤖 AI                        👤 เรา
 อธิบายสิ่งที่ต้องการ   →   เขียนโปรแกรมให้ทั้งหมด   →   ทดสอบ + บอกว่าต้องแก้อะไร
 (ภาษาพูดธรรมดา)            (สร้างไฟล์ รัน ทดสอบเอง)       (วนจนพอใจ)
```

- **ไม่ต้องรู้** ภาษาโปรแกรม
- ทักษะที่ต้องใช้ = **ทักษะเดียวกับ Module 1** — อธิบายให้ชัด
- **เราเป็นคนตัดสินใจ** — AI ขออนุญาตก่อนทำทุกครั้ง

---

## 2.2 ทำเองได้ vs ควรส่งต่อ IT

| ✅ ทำเองได้ | ⛔ ส่งต่อ IT / ผู้เชี่ยวชาญ |
|---|---|
| สูตร Excel, จัดระเบียบตาราง | ระบบที่เชื่อมฐานข้อมูลจริง |
| เครื่องคำนวณ, แบบฟอร์มส่วนตัว | ระบบเกี่ยวกับสิทธิ์ / ความปลอดภัย |
| หน้าเว็บแนะนำหน่วยงานอย่างง่าย | ระบบที่เปิดให้ประชาชนใช้วงกว้าง |
| ต้นแบบไว้คุยกับทีม IT | ระบบที่เก็บข้อมูลส่วนบุคคล |

## 2.3 ให้ AI สร้างสูตร Excel

```text
ฉันมีตาราง Excel คอลัมน์ A = วันที่, B = สถานะ, C = ประเภทบริการ,
D = จังหวัด, E = จำนวนตำแหน่งที่สมัคร ข้อมูลอยู่แถว 2 ถึง 200
ช่วยเขียนสูตรนับจำนวนผู้มาติดต่อในเดือนกันยายน 2026
ที่มีสถานะ "Active" ในคอลัมน์ B อธิบายสั้น ๆ ว่าสูตรทำงานอย่างไร
```

⬇️

```text
=COUNTIFS(B2:B200,"Active",A2:A200,">="&DATE(2026,9,1),A2:A200,"<="&DATE(2026,9,30))
```

> 💡 แปะข้อมูลตัวอย่าง (ที่ไม่มีข้อมูลส่วนบุคคล) 5–10 แถว → ได้สูตรตรงกว่า

## เครื่องมือที่ใช้: Claude Code (AI CLI)

- AI ที่ทำงานใน **Terminal** — สร้างไฟล์ รันคำสั่ง ทดสอบผลได้เอง
- ทำงานบน **VM ของเราเอง** (Ubuntu บนคลาวด์)
- **ขออนุญาตก่อนทุกครั้ง:**

```text
 Do you want to create index.html?
 ❯ 1. Yes
   2. Yes, allow all edits during this session (shift+tab)
   3. No, and tell Claude what to do differently (esc)
```

⚠️ **อ่านก่อนกด** — AI จะทำสิ่งที่ไม่ได้สั่ง / ลบไฟล์ → เลือก **No** แล้วถาม TA

## ขั้นที่ 2: ล็อกอินผ่านลิงก์

VM ไม่มีเบราว์เซอร์ → ใช้เบราว์เซอร์ **บนเครื่องตัวเอง**

1. **คัดลอกลิงก์** `https://claude.ai/oauth/authorize?...` จาก Terminal
2. วางในเบราว์เซอร์ → ล็อกอิน → **Authorize**
3. คัดลอก **Authentication Code** ที่ได้
4. วางกลับใน Terminal ตรง `Paste code here if prompted >` → `Enter`
5. `Do you trust the files in this folder?` → **Yes, proceed**

🛟 ล็อกอินไม่ผ่าน → ใช้ **API Key** ในซองสำรอง (คู่มือ 03 กล่อง 🛟)

## ขั้นที่ 3: เลือกโจทย์ 1 ข้อ

| โจทย์ | เครื่องมือ |
|---|---|
| **A** ⭐ | เครื่องคำนวณวันลาคงเหลือ (แนะนำ) |
| **B** | แบบฟอร์มลงทะเบียนงานนัดพบแรงงาน |
| **C** | หน้าเว็บแนะนำหน่วยงาน |
| **D** | เครื่องคำนวณวันครบกำหนด |
| **E** | โจทย์ของตัวเอง |

- คัดลอก prompt จากคู่มือ → วางในช่อง `>` → `Enter`
- **ห้ามลบส่วน "ข้อกำหนดทางเทคนิค"** — ช่วงบ่ายต้องใช้
- ตรวจผลเอง: `!curl -s http://localhost:8080 | head -n 15`

## ขั้นที่ 4: สั่งแก้เฉพาะจุด แล้วออก

```text
เปลี่ยนสีหลักเป็นสีเขียวเข้ม และทำปุ่มให้ใหญ่ขึ้นสำหรับกดบนมือถือ
```

```text
อธิบายให้ฟังแบบคนไม่เคยเขียนโปรแกรม ว่าไฟล์ที่สร้างทำงานอย่างไร
```

| คำสั่งใน Claude Code | ทำอะไร |
|---|---|
| `!คำสั่ง` | รันคำสั่งเอง |
| `Esc` | หยุด AI |
| `/exit` | ออก |

## 2.6 ข้อจำกัดและข้อควรระวัง

1. **ทดสอบเสมอ** — ลองค่าแปลก ๆ (ว่าง, ติดลบ, ตัวเลขมาก ๆ)
2. **AI อาจผิดแบบมองไม่เห็นทันที** — เช่น นับวันทำการผิดบางกรณี
3. **ต้องให้ IT ตรวจ** ก่อนใช้กับข้อมูลจริง หรือเผยแพร่สาธารณะ
4. **ห้ามให้เครื่องมือเก็บข้อมูลส่วนบุคคล** โดยไม่ผ่านการตรวจตามระเบียบ

> 📌 ไม่ต้องลบอะไร — ช่วงบ่ายกลับมาต่อด้วย `cd ~/myapp && claude --continue`
