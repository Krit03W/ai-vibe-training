## Module 5 · 40 นาที

# ระบบ AI ค้นหา-ตอบคำถาม<br>จากเอกสารหน่วยงาน

RAG — ระดับแนวคิด + สาธิต

---

## 5.1 ทำไม AI ทั่วไปตอบเรื่องภายในไม่ได้

```text
ตามคู่มือการให้บริการของสำนักงานจัดหางานจังหวัดทดสอบ
ผู้หางานต้องใช้เอกสารอะไรบ้างในการลงทะเบียน
```

AI ทั่วไป → ตอบกว้าง ๆ หรือ **แต่งรายการขึ้นมาเอง**

เพราะ AI ฝึกจาก **ข้อมูลสาธารณะ** — **ไม่เคยเห็น** ระเบียบ / คู่มือ / เอกสารภายในของกรมฯ

> 🎬 **สาธิตสด**

---

## 5.2 RAG = บรรณารักษ์ค้นแฟ้ม

**R**etrieval-**A**ugmented **G**eneration — "ค้นก่อน แล้วค่อยตอบ"

```text
 👤 คำถาม ──▶ 🔎 ค้นหาแฟ้มที่เกี่ยวข้อง ──▶ 🤖 AI อ่านแล้วสรุป ──▶ 💬 คำตอบ + อ้างอิง
                     ▲
              🗄️ คลังเอกสารหน่วยงาน
```

| บรรณารักษ์ | ระบบ RAG |
|---|---|
| รับคำถามที่เคาน์เตอร์ | รับคำถามภาษาธรรมดา |
| เดินไปหยิบแฟ้ม 2–3 แฟ้ม | ค้นท่อนเอกสารที่ **ความหมาย** ใกล้ที่สุด |
| อ่านแล้วอธิบาย | AI อ่านเฉพาะท่อนที่ค้นเจอ แล้วเรียบเรียง |
| "อยู่ในแฟ้มระเบียบการลา หน้า 3" | แสดงชื่อเอกสาร / ข้อ ที่ใช้ตอบ |

---

## AI ทั่วไป vs AI + RAG

| AI ทั่วไป | AI + RAG |
|---|---|
| ตอบจากความรู้ที่เรียนมา | ตอบจาก **เอกสารของหน่วยงาน** |
| ไม่รู้ระเบียบภายใน | รู้ตามเอกสารในคลัง |
| บอกแหล่งอ้างอิงไม่ได้ | บอกได้ว่ามาจากเอกสารไหน |
| เสี่ยงแต่งคำตอบ | ตั้งให้ตอบ "ไม่พบข้อมูล" ได้ |
| อัปเดตความรู้ = ฝึกใหม่ | อัปเดต = **เปลี่ยนเอกสาร** |

---

## 5.3 องค์ประกอบของระบบ

| องค์ประกอบ | หน้าที่ |
|---|---|
| **คลังเอกสาร** | เก็บเอกสารดิจิทัลของหน่วยงาน |
| **ตัวแบ่งเอกสาร** (Chunking) | ตัดเอกสารยาวเป็นท่อนสั้น ให้ค้นแม่น |
| **ฐานข้อมูลค้นหา** (Vector DB) | เก็บ "ความหมาย" ของแต่ละท่อน |
| **ระบบค้นหา** (Retriever) | หาท่อนที่เกี่ยวกับคำถามที่สุด |
| **AI สรุปคำตอบ** (LLM) | อ่านท่อนที่ค้นเจอ แล้วเขียนคำตอบ |
| **ระบบสิทธิ์** | ใครค้นเอกสารอะไรได้ |

## 5.4 🎬 สาธิต

เอกสารสมมติ 3 ชิ้น: คู่มือบริการผู้หางาน · แนวปฏิบัติการลา · FAQ งานนัดพบแรงงาน

| # | คำถาม | สังเกต |
|---|---|---|
| 1 | ลงทะเบียนหางานต้องใช้เอกสารอะไร | ตอบตรง + อ้างอิง |
| 2 | ลาพักผ่อนสะสมสูงสุดกี่วัน ถ้าทำงานมา 12 ปี | รวมเงื่อนไขหลายข้อ |
| 3 | นายจ้างต้องจองบูธล่วงหน้าไหม | ค้นเจอใน FAQ |
| 4 | เงินเดือนข้าราชการแรกบรรจุเท่าไร | **ไม่มีในเอกสาร** → "ไม่พบข้อมูล" |
| 5 | ถามข้อ 1 กับ AI ทั่วไป | เทียบความต่าง |

## 5.5 เตรียมเอกสาร + ควบคุมสิทธิ์

| ✅ ดี | ❌ ปัญหา |
|---|---|
| ไฟล์ดิจิทัล คัดลอกข้อความได้ | PDF สแกนเป็นภาพ |
| มีหัวข้อ / เลขข้อชัดเจน | ข้อความยาวไม่มีหัวข้อ |
| ฉบับล่าสุดฉบับเดียว มีวันที่ | หลายฉบับปนกัน |

**สิทธิ์:** ระบบต้องค้นเฉพาะเอกสารที่ **ผู้ถามมีสิทธิ์เห็น** + มี log ตรวจสอบย้อนหลัง

## 5.6 ถ้าหน่วยงานจะพัฒนาระบบเอง

| ด้าน | เตรียม |
|---|---|
| **ขอบเขต** | ตอบเรื่องอะไร ใครใช้ (ภายใน / ประชาชน) |
| **เอกสาร** | คัดฉบับล่าสุด แปลงเป็นดิจิทัล มีเจ้าของเนื้อหา |
| **บุคลากร** | IT + เจ้าของเนื้อหา + DPO |
| **โครงสร้าง** | คลาวด์ หรือติดตั้งในหน่วยงาน |
| **งบประมาณ** | ค่า AI, เซิร์ฟเวอร์, พัฒนา, ดูแลรายปี |
| **ระยะเวลา** | ต้นแบบ → ทดลองกลุ่มเล็ก → ขยายผล |
| **วัดผล** | ชุดคำถาม-คำตอบมาตรฐานก่อนเปิดใช้ |
