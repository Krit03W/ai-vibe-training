## 4.1 ข้อมูลที่ห้ามนำเข้าระบบ AI

| ประเภท | ตัวอย่าง |
|---|---|
| **ข้อมูลส่วนบุคคล (PII)** | ชื่อ-นามสกุล, เลขบัตร ปชช., เบอร์โทร, ที่อยู่, อีเมล |
| **ข้อมูลอ่อนไหว** | สุขภาพ, ศาสนา, ประวัติอาชญากรรม |
| **ข้อมูลผู้รับบริการ** | ผู้สมัครงาน, ผู้ประกันตน, แรงงานต่างด้าว, นายจ้าง |
| **เอกสารลับราชการ** | ลับ / ลับมาก / ลับที่สุด, ร่างนโยบายที่ยังไม่เผยแพร่ |
| **รหัสผ่าน / API Key** | รหัส VM, API Key ของ AI CLI เมื่อเช้า |

> 🔗 API Key เมื่อเช้า = หลักเดียวกับข้อมูลส่วนบุคคล: **หลุดแล้วเรียกคืนไม่ได้**

## 4.2 บัญชีทั่วไป vs บัญชีองค์กร

| ประเด็น | บัญชีฟรี / ส่วนตัว | บัญชีองค์กร |
|---|---|---|
| นำข้อมูลไปฝึกโมเดล | อาจนำไปใช้ | โดยทั่วไปไม่นำไปใช้ตามสัญญา |
| ระยะเวลาเก็บข้อมูล | ตามนโยบายผู้ให้บริการ | กำหนดตามข้อตกลง |
| ผู้ควบคุม | ผู้ใช้คนเดียว | ผู้ดูแลระบบหน่วยงาน |

> 🎬 **สาธิต:** เมนูปิดการนำข้อมูลไปฝึกโมเดล (Settings → Data controls / Privacy)

## 4.4 PDPA — หน้าที่ของผู้ใช้งาน

| หลัก | ในการใช้ AI |
|---|---|
| **ใช้ตามวัตถุประสงค์** | ข้อมูลเพื่อบริการจัดหางาน ไม่ส่งให้ AI ภายนอก |
| **ใช้เท่าที่จำเป็น** | ตัดส่วนที่ระบุตัวตนออก |
| **รักษาความปลอดภัย** | ใช้เฉพาะระบบที่หน่วยงานอนุมัติ |
| **แจ้งเหตุ** | เผลอส่งไปแล้ว → แจ้งหัวหน้า / ผู้ดูแลระบบ / DPO **ทันที** |

**นโยบาย AI ของหน่วยงาน** ควรมี: เครื่องมือที่อนุญาต · ข้อมูลต้องห้าม · งานที่ต้องตรวจทาน · การระบุว่าสร้างด้วย AI · ช่องทางรายงานเหตุ

## 4.5 ภัยหลอกลวงที่สร้างด้วย AI

| ภัย | วิธีสังเกต / ป้องกัน |
|---|---|
| **อีเมลฟิชชิ่ง** (ภาษาเนียน ไม่มีคำผิด) | ดูอีเมลผู้ส่งจริง · ชี้ลิงก์ดู URL · เร่งรัดผิดปกติ = สงสัย |
| **Deepfake ภาพ / วิดีโอ** | แสงเงาแปลก · ขอบหน้า/ผม/หูเบลอ · นิ้วผิดรูป · ปากไม่ตรงเสียง |
| **Voice Cloning** | วางสาย → **โทรกลับเบอร์ที่รู้จัก** · ตั้ง "คำลับ" |

> 📌 **เงิน / รหัสผ่าน / ข้อมูลลับ + ความเร่งด่วน = หยุด → ตรวจสอบช่องทางอื่น → ค่อยทำ**

## ☑️ Checklist ก่อนกด "ส่ง" ทุกครั้ง

- ☐ ไม่มีชื่อ / เลขบัตร / เบอร์โทร / ที่อยู่ / อีเมลของคนจริง
- ☐ ไม่มีข้อมูลผู้รับบริการ
- ☐ ไม่ใช่เอกสารลับ หรือร่างที่ยังไม่เผยแพร่
- ☐ ไม่มีรหัสผ่าน / API Key / Token
- ☐ ใช้บัญชี / เครื่องมือที่หน่วยงานอนุญาต
- ☐ มีคนตรวจทานผลลัพธ์ก่อนใช้จริง
