## Key Takeaways — 5 Module

1. **Prompt Engineering** — บทบาท + บริบท + งาน + รูปแบบ + ข้อจำกัด แล้ว **ตรวจสอบข้อมูลเสมอ**
2. **Vibe Coding** — สร้างเครื่องมือด้วยภาษาพูด และ **deploy ขึ้นโดเมนจริงมาแล้ววันนี้**
3. **ผลิตสื่อด้วย AI** — "แก้ ไม่ใช่สร้างใหม่" · ระวังลิขสิทธิ์ · **ระบุว่าสร้างด้วย AI**
4. **ความปลอดภัย** — ห้ามใส่ข้อมูลส่วนบุคคล / เอกสารลับ / รหัสผ่าน · รู้ทันภัยหลอกลวง
5. **RAG** — "ค้นแฟ้มก่อน แล้วค่อยตอบ" · เข้าใจพอจะคุยกับทีม IT ได้อย่างมีหลักการ
